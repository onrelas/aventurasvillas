# Aventuras Villas Blog Platform

Platform choice: **Static blog on GitHub Pages** (no extra cost, no maintenance server).

## How to add a new post
1. Create a new file in `blog/posts/` using kebab-case, e.g. `best-cenotes-near-tulum.html`
2. Copy structure from an existing post.
3. Add a new card in `blog/index.html` linking to the new post.
4. Commit + push.

## Why this platform
- Zero monthly cost
- Fast load speed
- Simple editing from GitHub
- Works with existing `aventurasvillas` deployment
