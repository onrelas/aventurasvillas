# Lead Source Tracking (WhatsApp CTA)

All key WhatsApp CTAs now include an encoded source tag in prefilled message text.

Format inside incoming WhatsApp lead messages:

`Source: <page_or_post>_cta<index>`

Examples:
- `Source: index_cta3`
- `Source: blog_posts_invest-in-tulum-villas-2026_cta1`

## How to use
1. When lead messages arrive, check the `Source:` line.
2. Attribute each lead to page/post source.
3. Prioritize pages producing qualified buyer conversations.
